# Research Intelligence System 研究上下文

本仓库保存科研选题、评分规则、证据与决策记录。目标是选出值得投入 6—12 个月的研究问题。本地初筛使用 RTX 5060 8GB，完整研究所需的外部算力按候选估算。

## 当前结论

- 六维评分采用证据追溯、反证审查与分阶段决策；缺乏依据的项目保持“待验证”。
- 候选问题尚未完成六维评估，没有正式分数、总分、立项结论或顶会潜力认证。
- 撤回“视觉证据评估是当前明确首选”的判断：最近论文的附录已覆盖部分建议切口。
- 后续先完成最近工作比较和资源实测，再决定是否开展完整研究。

## 阅读顺序

先看[扩展选题池 Excel](outputs/科研选题池（扩展阅读版）.xlsx)。总览包含 13 个候选，六维详评列出评分状态、证据与待验证项，证据索引可追溯出处。

1. [CONTEXT.md](CONTEXT.md)：个人背景、目标、资源、讨论边界与下一步。
2. [评分规则](docs/scoring-policy.md)：六维判据、量化指标、评分分档与否决条件。
3. [候选问题审查](docs/topic-audit.md)：具体问题、已有工作、重合风险和缺失证据。
4. [证据登记](docs/evidence-register.json)：来源、定位、支持范围与局限。
5. [科研工具审查](docs/research-tools.md)：已调查框架及可借鉴方法。
6. [决策记录](docs/decision-log.md)：重要修正及其理由。
7. [评估模板](templates/topic-assessment.json)：保持空分数的可复用记录模板。

## 仓库范围

这是按用户要求新建的本地 Git 仓库，建立日期为 2026-11-05，主要用于上下文管理。用户曾描述一个 Python + Streamlit 评分器 MVP，但该代码及原仓库历史没有导入本仓库。本仓库尚未实现评分引擎、API 连接、自动实验或界面。

远程仓库为 [yantingweb/research-topic-evaluator](https://github.com/yantingweb/research-topic-evaluator)。实验记录区分建议、来源核查与实际运行。

## 更新约定

- 后续先读取 `CONTEXT.md` 与最新决策记录，保留背景，尊重最新修正。
- 新事实附来源及具体位置；论文报告、系统推测和自己的实验结果分别记录。
- 新证据可以降低分数、推翻推荐；保留修正原因和历史版本。
- 没有执行实验就不填写实验结果，没有完成查新就不宣称原创。
- 敏感信息和 API 密钥不进入 Git；第三方 skill 的内容需审查后按需采用。
